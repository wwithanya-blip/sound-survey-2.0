# Study 3b — cross-linguistic sound symbolism survey

Static site: five language versions of the same 40-item forced-choice listening task.

- `survey_study3b_{en,cn,ja,es,ar}_40.html` — the surveys
- `*.mp3` — 80 stimulus files + 5 audio-check files (`hello`, `nihao`, `konnichiwa`, `hola`, `marhaba`)
- `index.html` — language chooser

Item set: `A23_study3b_items_40.csv`, MD5 `e3f3517373ff67bc99abbdc5f38c45b9`.
Audio: Edge TTS `en-US-AriaNeural`, rate −10%, EBU R128 two-pass normalisation to −16 LUFS
(TP −1.5, LRA 11) — identical parameters to Study 3, so the two are directly comparable.
